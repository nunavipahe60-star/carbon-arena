# Three-player events

Both formats use exactly three registered final strategy versions. Confirm the final roster before freezing it. The freeze commits the source hashes, rules, runtime and policy before drawing maps. Starting the games is a separate action. Each archive supports one permanent roster for each format.

| Format | Shared maps | Games per pairing | Total games | Games per entrant |
| --- | --- | --- | --- | --- |
| Season Two | 6 | 12 | 36 | 24 |
| Curtain Call | 10 | 20 | 60 | 40 |

Each map is played in both colors. Combined cash decides its winner: 1 point for a win, 0.5 for an exact draw, 0 for a loss. Map points rank first, then total cash; equal points and cash share a rank. Only fully verified color pairs contribute provisional standings. All games finish.

Both events preserve the separate championship Elo/title ledger. Each game has a full strategy rerun and an independent comparison. An interruption pauses the season. Resume uses the same roster, maps and verified prefix; changed evidence or frozen runtime stops continuation.

Curtain Call additionally creates a local ZIP of completed results and the offline viewer. Its packaging reads only this installation's event records and public viewer files. It does not search neighboring organizer workspaces or include original private submissions.
