# Publication scope

This is a source-only publication of a personal, AI-assisted game experiment. Its public record starts with this release; no development timeline or prior GitHub contribution history is implied.

Included: rules 0.5, browser demo, championship and Practice workflows, both three-player season formats, sandbox, public WAIT/harvester examples, independent comparison tools, portable installation, and tests.

Excluded: original registered submissions, real match or season archives, sealed evidence, owner secrets and launcher capabilities, sessions, organizer receipts, preparation conversations, backups, old delivery packages, dependency installations, and local review materials.

New installations begin with empty standings and no champion. Included seed exclusions describe public fixtures only; this repository does not claim to carry the private installation's complete seed history. Results from independent archives do not share a calibrated rating pool.

Attribution in the independently authored resolver and comparator is retained. Model names in documentation identify collaboration or user-supplied labels; they do not imply endorsement or verified model identity. No fabricated development history or private strategy contribution is included.

The source kit is generated locally by `npm ci` or `npm run build:kit`. It includes the same public source, documentation and examples, with no installed dependencies or match records. Its installation uses the pinned package locks. Do not distribute local result packages without reviewing their contents: newly generated event receipts can contain entrant labels and local runtime information.
